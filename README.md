# BTR World

**Minecraft Java 1.21.1 · Fabric · Polymer · 0.5.1 beta**

Неофициальный фан-мод по «Одинокому рокеру»: приручаемые тсум и чиби, три вида концертных зданий, маленькая сцена, репетиции, палитры блоков и уютный декор. Работает на сервере с обычными Java-клиентами, принимающими ресурс-пак Polymer.

## Что есть в моде

- Редкие здания STARRY, школьного фестиваля и инди-клуба. В каждом — инструменты и четыре живые участницы (чиби, тсумы или смешанный квартет), которые играют при зрителях. [Гайд по сценам и командам](docs/stages-guide.md), [исследование оформления](docs/stage-research.md), [планы NBT](docs/stages-layout.png).
- Единые переводимые названия спутниц в RU/BE/EN для всех способов появления и ответов команд; миграция прежних автоматических русских имён.

- Восемь спутниц: Боччи, Нидзика, Рё и Кита в двух формах — тсум и чиби. Приручение, ожидание, три режима движения, размножение с наследованием героини и ускоряемое кормлением взросление.
- 55 блоков: 36 цветовых вариантов, фигурки, сценическое оборудование, гитара на стойке, коробка для посадки игрока, плюшевые игрушки, афиши и светильники.
- 72 рецепта, отдельная вкладка BTR World в `/polymer creative`, обычные уведомления достижений. Десять достижений переведены на русский, белорусский и английский.
- Четыре большие чиби-статуи как редкие структуры.
- Тихое напевание и репетиции у инструментов. В 0.4.1 репетиция длится 90–150 секунд, затем пауза 60–120 секунд. Это оригинальные нотные фразы и ванильные звуки, без аудиозаписей или транскрипций песен из аниме.
- Декоративные аксессуары и розовый костюм. Знак STOP декоративный; у одежды нет особых боевых бонусов.

## Установка на сервер

1. Запустите Minecraft **1.21.1** с **Fabric** и **Java 21**.
2. Установите в `mods`:
   - [Fabric API](https://modrinth.com/mod/fabric-api/versions?g=1.21.1) — сборка проверяется с `0.102.1+1.21.1`;
   - [Polymer bundled](https://modrinth.com/mod/polymer/versions?g=1.21.1) — сборка проверяется с `0.9.18+1.21.1`;
   - `btr-world.jar`.
3. Настройте раздачу ресурс-пака Polymer. Для bundled используется AutoHost; после первого запуска включите `enabled` в `config/polymer/auto-host.json` и перезапустите сервер. [Инструкция Polymer](https://polymer.pb4.eu/latest/user/resource-pack-hosting/).
4. При подключении примите серверный ресурс-пак. Без него модели и текстуры не отображаются корректно.

Клиентский BTR World не обязателен для игры на сервере. Для одиночной игры установите те же зависимости в игровой профиль. Для JEI на клиенте нужны BTR World, его зависимости и [JEI для Fabric 1.21.1](https://modrinth.com/mod/jei). Отдельная установка JEI не даёт ему доступ ко всем предметам серверного мода. Bedrock/Geyser в этой версии не проверен.

## Спутницы и управление

| Спутница | Любимая еда | Особенность |
|---|---|---|
| Боччи | Печенье | Убегает от враждебных мобов и прячется в коробку |
| Нидзика | Торт-предмет | Даёт спешку хозяину рядом и сокращает панику Боччи |
| Рё | Пшеница | Ест траву; у хозяина меняет изумруд на фигурку |
| Кита | Светящиеся ягоды | Частицы/контур и ночное зрение хозяину; не освещает блоки |

Нажимайте по нижней части фигурки: там область взаимодействия.

| Действие | Управление |
|---|---|
| Приручить / лечить | ПКМ любимой едой |
| Посадить ждать / снова отпустить | ПКМ пустой рукой |
| Режим движения | Shift + ПКМ палкой: следовать → ближе → гулять примерно в радиусе 16 блоков от хозяина |
| Выключить/включить музыку | Shift + ПКМ пустой рукой; настройка сохраняется |
| Размножить | Накормить двух своих здоровых взрослых спутниц любимой едой каждой |
| Ускорить рост малыша | Любимая еда: минус 10% оставшегося времени роста за угощение |
| Дать имя / вести | Обычная бирка / поводок |
| Сесть в поставленную коробку | ПКМ по коробке; Shift — выйти |

Пара подходит лицами друг к другу с сердечками перед появлением малыша. Героиня потомка выбирается с весами; внешние черты не смешиваются. Нидзика + Боччи: 75% / 25%. [Подробный гайд питомцев](docs/pet-care.md).

## Репетиция

Поставьте инструмент в пределах восьми блоков от приручённой взрослой спутницы, отпустите её из ожидания и оставайтесь в пределах 16 блоков. Нужен свободный проход.

| Героиня | Блок | Звук |
|---|---|---|
| Нидзика | `bocchi:drum_kit` | Барабанный ритм |
| Кита | `bocchi:microphone` | Мелодия флейты |
| Боччи | `bocchi:guitar_stand` | Гитара |
| Рё | `bocchi:guitar_stand` | Бас |

Игра сопровождается нотными частицами и поворотом к инструменту. Паника, ожидание, готовность к размножению, выключенная музыка и уход хозяина прерывают репетицию. Модели статичные: анимации рук пока нет. Громкость регулируется категорией «Дружелюбные существа».

## Крафты и команды

**[Полный справочник всех 72 рецептов](docs/CRAFTING.md)** — схема верстака, точные ингредиенты, количества и результат. Справочник генерируется из JSON-рецептов, а не поддерживается вручную.

- `/polymer creative` — вкладка BTR World.
- `/bocchi stage` — небольшая сцена на свободном участке 7×4×5 перед игроком по оси +Z; нужен оператор уровня 2.
- `/locate structure bocchi:heroine_statue` — ближайшая статуя любой героини.
- `/place template bocchi:statues/nijika` — конкретная статуя; вместо `nijika` также доступны `bocchi`, `ryo`, `kita`.
- `/recipe give @s *` — открыть рецепты оператором.

## Сборка и публикация

```bash
bash ./gradlew build
python3 scripts/validate_assets.py
python3 scripts/prepare_release.py
```

Нужна Java 21. Готовый мод: `release-assets/btr-world.jar`.

GitHub Actions проверяет ресурсы, генетику и проверку публикации, собирает мод на push/PR и автоматически публикует успешный актуальный коммит основной ветки в GitHub Releases. Файлы имеют постоянные имена: JAR, исходники и SHA256.

Статическая ссылка после загрузки проекта в свой репозиторий:

```text
https://github.com/<OWNER>/<REPOSITORY>/releases/latest/download/btr-world.jar
```

Modrinth-публикация включается переменной репозитория `MODRINTH_PROJECT_ID` и секретом `MODRINTH_TOKEN`. Загрузку выполняет `cloudnode-pro/modrinth-publish@v2.5.2`: beta-версии имеют статус `listed` внутри существующего **unlisted** проекта. После загрузки CI читает запись API и сверяет SHA512 обоих JAR. [Пошаговая подготовка и ограничения](release/PUBLISHING.md). Workflow подготовлен локально; без вашего репозитория и проекта внешние релизы не созданы.

## Полный справочник крафтов

Все рецепты выполняются на верстаке. В схеме строки отделены `/`, знак `·` означает пустую ячейку. Например, `PPP / PIP / PPP`: три доски сверху, доска–ингредиент–доска посередине и три доски снизу. Буквы указаны в колонке ингредиентов; количества относятся ко всему рецепту. «Любой порядок» — бесформенный рецепт, расположение не важно.

Предметы имеют префикс `bocchi:`. Рецепты доступны в книге рецептов после входа; команда оператора `/recipe give @s *` открывает все рецепты. Для просмотра в JEI нужны клиентские JEI, BTR World и его зависимости.

## Polymer: проверка состояний блоков

Версия 0.4.1 проверена при обычном запуске и искусственном исчерпании общих пулов Polymer. Проверены все 80 состояний 55 блоков и их collision caches. Если состояния для модели закончились, декор пробует второй tripwire-пул, затем безопасный AIR; полноразмерные блоки используют белую шерсть. Сервер не получает null, но недоступные модели будут отсутствовать/заменены до освобождения ёмкости пула. Лог предупреждения содержит ID каждой модели.

CI запускает Minecraft до проверки EULA, без создания игрового мира, в обоих режимах. Это проверяет инициализацию и pack, но не игровую сессию и не чужие моды сервера.

### Коробка и расстояние следования (0.4.2)

Коробку из-под манго и ахоге можно надеть ПКМ или переместить в слот шлема. Для ванильного клиента используется носимый предмет с моделью из ресурс-пака (в первом лице действует ванильная маска тыквы).

В обычном режиме питомец начинает догонять только при расстоянии **больше 32 блоков**, идёт пешком и останавливается, приблизившись до 24 блоков. Режим «держаться рядом» сохраняет близкое следование; переключение — Shift + ПКМ палкой. Посаженный питомец остаётся на месте. Следование работает в загруженных чанках и требует доступного пути.

## Проверка дополнений 0.5.0

Локально прошли проверки JSON/NBT, всех девяти сценических шаблонов, позиций 36 мобов, доступного пола, оборудования и ссылок worldgen; 9 Python-тестов. Новая Java-сборка и Minecraft-запуск локально не выполнены: в этой среде нет JDK 21 и кеша Gradle, а загрузка зависимостей недоступна. Готовый JAR 0.4.2 не содержит новые сцены. В архиве 0.5.0 поставляются исходники; существующий GitHub CI собирает новый JAR и выполняет дополнительные проверки сцен/миграции в Minecraft перед публикацией. Игровой вид и поведение квартета требуют проверки после сборки.

### Исправление проверки 0.5.1

Проверка сохранения имён использует полные `Entity.writeNbt/readNbt`, которые обрабатывают `CustomName`, вместо методов только данных питомца. Проверки Minecraft в CI сохранены; игровой мир не запускается. Новая Java-сборка локально не выполнена из-за недоступности зависимостей.
