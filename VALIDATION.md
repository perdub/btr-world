# Проверки версии 0.1.0

Проверено 3 октября 2026 года.

- Java 21, Gradle 8.8, Fabric Loom 1.7.4: `build` — **BUILD SUCCESSFUL**.
- Fabric Loader 0.16.10, Fabric API 0.102.1+1.21.1, Polymer 0.9.18+1.21.1: загрузка серверного entrypoint прошла. В журнале подтверждена регистрация 8 спутников и 47 блоков.
- Проверка Mixin прошла в среде разработки; у итогового remapped JAR присутствует refmap с intermediary-именами всех трёх invoker-методов.
- Polymer действительно собрал ресурспак. Проверена целостность ZIP, 65 CustomModelData-переопределений предмета paper и наличие всех моделей, на которые они ссылаются.
- `scripts/validate_assets.py`: **PASS**, 267 JSON-файлов, ссылки на текстуры/модели, допустимые координаты и углы, 47 таблиц выпадения и 56 рецептов в формате 1.21.1.
- Превью моделей просмотрено; поправлены перекрытия лиц плюшевых форм. Превью — программный ортографический рендер геометрии, а не скриншот Minecraft.

## Границы проверки

Сервер остановился на стандартном требовании EULA; соглашение автоматически не принималось, игровой мир не запускался. Поэтому **в игровом мире ещё не проверены** приручение, движение/телепортация, сохранение после перезапуска, торговля, частицы, естественное появление, крафт, коллизии и клиентский рендер моделей. Это первая проверочная сборка, а не полностью протестированный релиз.

Автоматических GameTest/JUnit-сценариев нет; Gradle сообщил `test NO-SOURCE`. Успешная сборка сама по себе не доказывает игровое поведение.

## Особенности среды сборки

В этой среде недоступны Unix domain sockets. В локальном кэше инструмента Loom его проверка этой необязательной возможности была изменена так, чтобы возвращать `false` при IOException; также отключена необязательная диагностика блокировок через native-библиотеку. Эти локальные изменения относятся к инструменту сборки и не входят в JAR или исходники мода. Обработка исходников сторонних зависимостей была пропущена штатным режимом CI. На обычной машине сборка использует оригинальный Loom через Gradle wrapper.

## Исправление текстур 0.1.1

Скриншот Алиски подтвердил: геометрия отображается, но общие текстуры фигурок и декора отсутствуют. Проверка `assets/minecraft/atlases/blocks.json` из оригинального Minecraft 1.21.1 показала, что каталог `textures/model` не включён в стандартный атлас. Текстуры перенесены в `textures/block/model`, ссылки и генератор обновлены. Валидатор теперь отвергает ссылки за пределами каталогов `block/` и `item/`, даже если PNG существует.

Обновление JAR выполнено заменой ресурсов в ранее собранном remapped JAR; Java-классы и refmap не изменены. Проверены целостность JAR, ссылки, охват текстур оригинальным атласом 1.21.1 и воспроизводимость генерации ресурсов. Повторный клиентский запуск Minecraft в этой среде не выполнялся.

## Обновление 0.2.0

Полная сборка Java и remapped JAR выполнена с Java 21 и Gradle 8.10.2: BUILD SUCCESSFUL. JEI 19.21.0.247 использован только как compile-only зависимость; его классы не вложены в JAR. При локальной сборке использована опция `-PjeiLocalJar`; обычная сборка и CI получают зависимость из Maven BlameJared.

Диагностический запуск Fabric без JEI прошёл: зарегистрированы 56 игровых предметов, 40 визуальных моделей (8 спокойных + 32 выражения), новая Mixin-трансформация display-сущности и переключение ItemStack. В FakeWorld измерена посадочная высота ванильного волка 0.81875 блока и проверена запись обратного смещения в NBT tracked-трансформации. Polymer собрал обновлённый ресурспак. Для генерации предварительно загружен оригинальный client.jar, запрошенный Polymer, с проверкой SHA1, поскольку Java не имела прямого доступа к хосту загрузки. Сервер затем остановился на требовании EULA; мир не запускался.

Валидатор проверяет 299 JSON, включение текстур в атлас, геометрию, 47 выпадений и 56 схем крафта без конфликтов. Просмотрено программное превью деталей и выражений. Игровая проверка посадки, побега/следования группы, появления четвёрки, сохранения группы, JEI и переноса ингредиентов пока не выполнена. Это проверочная сборка.
