# Настоящие скриншоты для галереи

Готовых одобренных для Modrinth картинок в этом каталоге пока нет. Не загружай AI-превью из `internal-previews` на Modrinth. Нужны реальные снимки Minecraft без генеративного редактирования и отдельно нарисованная человеком иконка либо отсутствие иконки.

Рекомендуемое разрешение снимков: 1920×1080; F1 убирает HUD, F2 сохраняет скриншот. Отключи F3+B, открой сцену при приятном дневном свете и сделай отдельный вечерний кадр освещения. Не добавляй модели/свет/анимации, отсутствующие в моде. Спокойный vanilla-рендер удобнее для честного сравнения.

Для сцены: `/bocchi stage`, затем добавь гитары на стойках и питомцев через creative-вкладку. Для статуи: `/place template bocchi:statues/nijika`; варианты `bocchi`, `ryo`, `kita`. При ручной установке подпись не должна утверждать, что это найденная естественная генерация.

Для иконки: нарисуй вручную квадрат 512×512 со своей простой звездой/ноткой и четырьмя цветами палитры. Избегай чужих официальных логотипов. Иконка должна читаться при уменьшении до 64×64. Наличие иконки не заменяет требуемых правил раскрытия AI-вклада проекта.
