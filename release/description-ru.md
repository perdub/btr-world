# BTR World

Неофициальный фан-мод по **«Одинокому рокеру»** для **Minecraft Java 1.21.1**, Fabric и Polymer. Приручи маленькую группу, оформи комнату для репетиций и поставь инструменты — спутницы смогут подходить и играть.

## Спутницы

Боччи, Нидзика, Рё и Кита в двух формах: тсум и чиби — восемь типов.

Любимая еда приручает и лечит; кормление малыша ускоряет рост. Доступны ожидание, обычное и близкое следование, прогулки около хозяина. Размножение работает между разными героинями и формами; потомок получает личность героини без смешивания внешних черт.

Боччи убегает от опасности и прячется, Рё ест траву и меняет изумруды на фигурки, Кита сияет и даёт ночное зрение, Нидзика даёт спешку и помогает успокоить Боччи.

## Декор и музыка

**55 блоков и 72 рецепта**: четыре цветовые палитры, фигурки, сценическое оборудование, гитара на стойке, коробка для посадки, плюшевые игрушки, постеры, неоновая звезда и гирлянды. Аксессуары и костюм декоративные.

Здоровые взрослые приручённые спутницы подходят к инструментам и играют **90–150 секунд** с нотными частицами. Нидзика — барабаны, Кита — флейта у микрофона, Боччи — гитара, Рё — бас. Мелодии оригинальные, на ванильных нотных звуках; записи песен из аниме и их транскрипции не включены. Анимации рук пока нет.

Есть четыре структуры чиби-статуй и десять достижений на русском, белорусском и английском.

## Установка

Нужны **Java 21, Fabric Loader, Fabric API и Polymer bundled** для Minecraft 1.21.1. Установи мод и зависимости на сервер, настрой раздачу ресурспака Polymer. Обычному Java-клиенту мод не обязателен, но нужно принять серверный ресурспак. Для одиночной игры установи те же зависимости в игровой профиль. Для JEI нужны клиентские BTR World, зависимости и JEI Fabric. Bedrock/Geyser не проверен.

| Действие | Управление |
|---|---|
| Приручить / лечить / ускорить рост | Печенье для Боччи, торт-предмет для Нидзики, пшеница для Рё, светящиеся ягоды для Киты |
| Посадить ждать / отпустить | ПКМ пустой рукой по нижней части своей спутницы |
| Режим движения | Shift + ПКМ палкой |
| Музыка | Shift + ПКМ пустой рукой |
| Сесть в коробку | ПКМ; Shift — выйти |

Предметы находятся в отдельной вкладке BTR World в `/polymer creative`. Для поиска статуи: `/locate structure bocchi:heroine_statue`.

## Статус и происхождение

Это beta. Сборка, проверка ресурсов и наследования не заменяют игровой тест.

Существенная часть кода, ассетов, переводов и документации подготовлена генеративным ИИ по идеям и обратной связи Алиски. Мод не использует генеративный ИИ во время игры. Подготовлен вариант unlisted-распространения в соответствии с текущими ограничениями Modrinth; решение о доступности остаётся за модерацией.

Фан-проект не связан с авторами «Одинокого рокера», Mojang и Microsoft. MIT относится к собственной реализации и не передаёт права на оригинальное произведение. Кадры аниме, записи саундтреков и готовые сторонние модели не включены.
