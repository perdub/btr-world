## BTR World 0.4.0 beta

- Instrument performances now last 90–150 seconds instead of six seconds.
- Added longer original note-block phrases with verse/response/refrain variations.
- Nijika plays percussion, Kita uses flute tones, Bocchi guitar and Ryo bass.
- Performances stop when the companion is told to wait, starts breeding, panics, or the owner leaves.
- Includes all previous content: eight tameable companions, 55 blocks, 72 recipes, costumes, plush toys, posters, lights, statues and advancements.
- Prepared GitHub and Modrinth CI/CD, complete crafting guide and release documentation.

This is a beta. Gameplay and visuals require testing on Minecraft Java 1.21.1.
No anime soundtrack recordings or song transcriptions are included. Performances use original phrases and vanilla Minecraft sounds.
Code, assets and text were developed with substantial generative AI assistance.
